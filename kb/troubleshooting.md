# Troubleshooting

## App crashes on start
Update the app to the latest version, restart the phone, and try again. If it still crashes, reinstall the app. Orders and saved items are kept in the account.

## Checkout errors
Clear the browser cache or try a different browser. Check that the card billing address matches the bank records. A declined card must be sorted out with the bank.

## Promo code not working
Promo codes cannot be combined and each code works only once per customer. Expired codes cannot be reactivated.

## Page not loading
Check the internet connection and try again in a few minutes. Disable browser extensions that block content, then reload the page.
