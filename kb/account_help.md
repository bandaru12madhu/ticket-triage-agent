# Account help

## Resetting a password
Use the Forgot password link on the sign in page. A reset email arrives within a few minutes. The link works for 1 hour. Check the spam folder if it does not arrive.

## Changing the email address
Go to Settings, then Profile, and enter the new email. A confirmation message is sent to the new address.

## Deleting an account
Account deletion is done from Settings, then Privacy. It removes saved addresses and order history and cannot be undone.

## Locked account
After 5 wrong passwords the account is locked for 30 minutes. Resetting the password unlocks it right away.
